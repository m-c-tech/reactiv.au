Secret GIF Builder

Paint some pixel art animations using off and 3 active colors. Build frame-by-frame animations, then export the C array code from the text box and send it to me.

How To Use

  1. Pick one of Off, Color 1, Color 2, or Color 3 and paint the grid.
  2. Use Frame controls to add, duplicate, or clear frames.
  3. Edit palette colors, choose presets, and save custom palette names.
  4. Copy the Pixel Frame Data output to share animation plus palette and sequence metadata.
  5. Use the sequencer to generate more with less. Reuse frames and apply mirrors per step.
